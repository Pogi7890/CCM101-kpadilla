## Principle of Least Privilege (PoLP)
PoLP is a security practice that limits each account to the minimum access required for its work. For cloud administrators, this helps prevent unnecessary access to sensitive resources and lowers the impact of stolen credentials.

## Attack Surface
An attack surface is the collection of points where an unauthorized person might try to enter or interact with a system. Open network ports, outdated applications, and unnecessary services can increase this surface and create additional security risks.

## Default Deny Policy
Default Deny rejects incoming traffic unless the firewall has an explicit rule permitting it. Instead of trying to identify every possible threat, administrators allow only required connections, such as SSH for administration and HTTP traffic for the web application.
