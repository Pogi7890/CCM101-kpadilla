# Laboratory Reflection

## 1. Which cloud infrastructure component is most important to you?

I consider networking to be one of the most important cloud infrastructure components because it allows systems and users to communicate. Cloud applications depend on network connections to receive requests and send information to users and other services.

## 2. How does Linux support cloud computing?

Linux provides a flexible environment for servers and virtual machines. It includes tools that allow administrators to monitor system resources, manage files, configure networks, and control processes. During this laboratory, Linux commands were used to inspect the resources available in the virtual environment.

## 3. Why is infrastructure documentation important?

Infrastructure documentation provides a clear record of the components and configuration of a system. It helps administrators understand the environment, plan changes, and troubleshoot problems. Documentation also makes it easier for other team members to understand how resources are organized.

## 4. What did you learn from this activity?

This activity helped me understand how to identify important server resources using Linux commands. I learned how to separate system information from network and storage information. I also improved my understanding of the basic components that work together in a cloud environment.

## 5. How did this activity improve your GitHub portfolio?

The laboratory added more organized technical documentation to my GitHub portfolio. The repository now includes reports, infrastructure explanations, screenshots, a cloud provider comparison, and an architecture diagram. This helps show my progress while learning cloud computing and Linux administration.
