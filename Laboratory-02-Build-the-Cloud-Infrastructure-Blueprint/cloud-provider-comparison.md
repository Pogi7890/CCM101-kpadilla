# Cloud Provider Comparison

## Service Comparison

| Infrastructure Category | AWS        | Microsoft Azure                   | Google Cloud     |
| ----------------------- | ---------- | --------------------------------- | ---------------- |
| Compute                 | Amazon EC2 | Azure Virtual Machines            | Compute Engine   |
| Storage                 | Amazon S3  | Azure Blob Storage                | Cloud Storage    |
| Networking              | Amazon VPC | Azure Virtual Network             | Google Cloud VPC |
| Identity Management     | AWS IAM    | Microsoft Entra ID and Azure RBAC | Cloud IAM        |

## Questions and Answers

### 1. Which provider offers a large selection of cloud services?

AWS offers a broad range of services for different cloud workloads. These services support areas such as computing, storage, databases, networking, security, analytics, and application development.

### 2. Which provider may be suitable for organizations using Microsoft technologies?

Microsoft Azure can be a suitable option for organizations that already use Microsoft products and services. Its cloud environment can work closely with Microsoft-based systems and identity management tools.

### 3. Which provider is known for AI, machine learning, and container technologies?

Google Cloud is recognized for services related to artificial intelligence and machine learning. It also provides Google Kubernetes Engine for managing containerized applications.

### 4. What do the three cloud providers have in common?

AWS, Azure, and Google Cloud all provide the basic infrastructure required for cloud computing. Each platform offers services for computing, storage, networking, security, and access management.

## Conclusion

The names of cloud services differ between providers, but their basic purposes are often similar. Understanding the function of each service category makes it easier to compare cloud platforms and identify equivalent infrastructure services.
