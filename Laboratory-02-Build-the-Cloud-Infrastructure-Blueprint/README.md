# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Overview

This laboratory activity focused on identifying and understanding the basic resources that support a cloud computing environment. A Linux server was examined using KillerCoda to gather information about its system configuration, networking, and storage.

The activity also included comparing major cloud providers and creating a simple cloud infrastructure design.

## Objectives

* Examine the resources of a Linux server.
* Identify system, compute, network, and storage information.
* Explain the purpose of important cloud infrastructure components.
* Compare services from major cloud providers.
* Create a basic cloud architecture.
* Document technical findings using Markdown and GitHub.

## Environment

The laboratory was completed using KillerCoda and an Ubuntu Linux environment. The system contained virtual compute resources, memory, storage, and networking components.
