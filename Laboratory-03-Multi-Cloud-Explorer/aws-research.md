# Amazon Web Services Research

## Brief Overview

Amazon Web Services, also known as AWS, is a cloud computing platform that provides services for computing, storage, databases, networking, security, analytics, and other workloads.

## Global Infrastructure

AWS has a global cloud infrastructure that allows organizations to deploy services in different geographic locations. Its infrastructure is designed to provide availability and support applications that serve users in different parts of the world.

## Cloud Management Console

The AWS Management Console is a web-based interface that allows users to create, configure, monitor, and manage AWS services.

## Four Core Services

### Amazon EC2

Amazon Elastic Compute Cloud provides virtual servers that can run applications and operating systems.

### Amazon S3

Amazon Simple Storage Service provides object storage for files, backups, media, and other types of data.

### Amazon VPC

Amazon Virtual Private Cloud allows users to create and manage private virtual networks for AWS resources.

### AWS IAM

AWS Identity and Access Management is used to control access to AWS resources through users, groups, roles, and permissions.

## Three Advantages

1. AWS provides a wide range of cloud services.
2. It supports scalable infrastructure for different workloads.
3. It has global infrastructure for deploying applications in different locations.

## Typical Enterprise Use Cases

AWS can be used for web applications, databases, file storage, backups, enterprise systems, analytics, and large-scale online services.
