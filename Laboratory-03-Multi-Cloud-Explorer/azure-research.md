# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform that provides services for computing, storage, networking, databases, security, artificial intelligence, and application development.

## Global Infrastructure

Azure operates through a global infrastructure with regions and datacenters located in different parts of the world. Organizations can deploy resources in locations that meet their performance and availability requirements.

## Cloud Management Console

The Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources.

## Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provide virtual computing resources for running Windows and Linux operating systems.

### Azure Blob Storage

Azure Blob Storage is used for storing large amounts of unstructured data such as files, images, videos, and backups.

### Azure Virtual Network

Azure Virtual Network provides networking services for connecting and managing Azure resources.

### Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users, applications, and cloud resources.

## Three Advantages

1. Azure has strong integration with Microsoft technologies.
2. It supports both cloud and hybrid environments.
3. It provides a wide range of services for organizations.

## Typical Enterprise Use Cases

Azure can be used for enterprise applications, Windows Server workloads, databases, Microsoft environments, virtual machines, and hybrid cloud systems.
