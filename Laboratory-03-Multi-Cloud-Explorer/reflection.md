# Mission Reflection

After completing this laboratory activity, I gained a better understanding of the differences and similarities between AWS, Microsoft Azure, and Google Cloud Platform. Before doing this activity, I knew that these platforms provided cloud services, but I did not fully understand how their services could be compared based on the needs of different organizations.

The cloud platform that impressed me the most was Google Cloud Platform. I found its services related to artificial intelligence, computing, and Kubernetes interesting because these technologies are important in modern application development. However, I also learned that AWS and Microsoft Azure have their own strengths and can be better choices depending on the situation.

One similarity among AWS, Azure, and Google Cloud is that all three platforms provide computing, storage, networking, identity management, and database services. These services allow organizations to build and run applications without depending completely on physical servers. All of them also provide scalable resources that can be adjusted based on the needs of an application or organization.

This activity also showed me that business requirements are important when choosing a cloud platform. A university or company that already uses Microsoft technologies may benefit more from Azure. An organization that focuses on artificial intelligence and machine learning may consider Google Cloud. A business that needs a large selection of cloud services may find AWS more suitable.

While completing the activity, I learned to think about cloud computing from the perspective of a Cloud Solutions Consultant. Instead of simply choosing the most popular platform, I learned that the services and requirements of the client should be considered before making a recommendation.

My GitHub Cloud Computing Portfolio also improved because I was able to add another organized laboratory activity. The repository now contains research, comparisons, recommendations, system information, screenshots, and my personal reflection. Using KillerCoda also helped me understand how the specifications of a Linux server can be connected to virtual machine services in different cloud platforms.
