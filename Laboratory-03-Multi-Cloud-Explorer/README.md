# Mission 3: Become a Multi-Cloud Explorer

## Overview

This laboratory activity focuses on exploring and comparing three major cloud platforms: Amazon Web Services, Microsoft Azure, and Google Cloud Platform. The activity includes researching their services, comparing their features, and recommending the most suitable platform for different business requirements.

## Linux Environment Information

The Linux environment used in this laboratory has the following specifications:

- Operating System: Ubuntu 24.04.4 LTS
- Kernel Version: 6.8.0-138-generic
- CPU: Intel Xeon E312xx (Sandy Bridge, IBRS update)
- CPU Cores: 1
- Total Memory: 1.9 GiB
- Available Memory: 1.5 GiB
- Swap: 1.0 GiB
- Main Disk Size: 19 GiB
- Available Disk Space: 13 GiB

## Cloud Migration

If this Linux server were migrated to the cloud, it could be hosted using virtual machine services from the three cloud providers.

### AWS

Amazon EC2 can be used to create and run a Linux virtual machine. The server specifications can be selected based on the required CPU, memory, storage, and network resources.

### Microsoft Azure

Azure Virtual Machines can host a Linux operating system and provide configurable computing, memory, storage, and networking resources.

### Google Cloud Platform

Google Compute Engine can host the Linux server using a virtual machine instance. The machine type and resources can be selected depending on the workload.

## Conclusion

The Linux environment used in KillerCoda helped me understand how a traditional server can be moved to the cloud. Instead of depending on physical hardware, cloud providers allow users to create virtual machines and adjust resources depending on their requirements.
